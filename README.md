## 📖 프로젝트 개요  

초등학생의 **자기주도 학습**을 돕는 온라인 **LMS 서비스**입니다.  
아이들이 스스로 학습 계획을 세우고, 다양한 콘텐츠(영상, 퀴즈, 커뮤니티 등)를 통해 학습을 이어갈 수 있도록 지원합니다.  

> **학습 효율 극대화와 흥미 유발을 위해**  
> AI(ChatGPT), OCR(Clova OCR), 랭킹 시스템, 커뮤니티 기능 등을 결합하여  
> 아이들이 **재미있게 학습**하고 **꾸준히 성장**할 수 있는 환경을 제공합니다.  

- **개발 기간**: 2024.04.02 ~ 2024.05.26   
- **팀 구성**: 프론트엔드 2명, 백엔드 1명, 디자이너 1명
